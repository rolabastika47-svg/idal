# OMSAR Social Share Plugin

**Version:** 1.0.0  
**Author:** IDS Company  
**Author URI:** https://ids.com.lb

## Description

Custom social media sharing plugin for WordPress. Allows users to share content on Facebook, Twitter, LinkedIn, WhatsApp, and copy links. Fully configurable through WordPress admin settings.

## Features

- ✅ Enable/Disable individual social media platforms
- ✅ Select which post types to display share buttons
- ✅ Choose button position (Banner, After Content, or Both)
- ✅ Modern modal popup interface
- ✅ Copy link functionality with visual feedback
- ✅ Responsive design
- ✅ Multilingual support (Polylang compatible)

## Installation

1. Upload the `omsar-social-share` folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to Settings > Social Share to configure options

## Configuration

Navigate to **Settings > Social Share** in WordPress admin to:

- Enable/Disable social media platforms:
  - Facebook
  - Twitter
  - LinkedIn
  - WhatsApp
  - Copy Link

- Select Post Types: Choose which post types should display the share button

- Button Position: Choose where to display the share button
  - Banner (Top Right)
  - After Content
  - Both

## Usage

Once activated and configured, the share button will automatically appear on the selected post types. Users can click the share button to open a modal with all enabled sharing options.
